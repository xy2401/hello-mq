# ActiveMQ Artemis 版本演进

ActiveMQ Artemis 是 Apache 官方下一代高性能多协议（JMS 2.0 / Jakarta Messaging, AMQP 1.0, MQTT, STOMP）消息代理。

## 版本索引

### [Artemis 2.42](./artemis-2.42)

- **发布时间：** 2025 年 7 月
- **版本重点：** 官方当前正式版本，运行基线为 Java 17+，并继续提供多协议代理与集群能力。

### [Artemis 2.36+](./artemis-2.36)

- **发布时间：** 2024 年 8 月
- **版本重点：** 全面支持 Jakarta Messaging 3.1 规范与 JDK 21 运行环境。

### [Artemis 2.0](./artemis-2.0)

- **发布时间：** 2017 年 3 月
- **版本重点：** 正式确立为 Apache ActiveMQ 的下一代代码主干。

## 升级建议
- 支持平滑接收来自 ActiveMQ Classic 的 OpenWire 客户端流量，是旧系统现代化的首选目标。
