# Apache RocketMQ 版本演进

Apache RocketMQ 5.0 实现了向云原生、无状态计算与轻量 gRPC 客户端的架构重构。

## 核心版本演进与关键里程碑

### RocketMQ 5.3（2024 年 8 月）

**主要功能与架构演进：**

- 正式推出分层存储（Tiered Storage）生产级支持，冷数据自动沉降至 S3/OSS 等对象存储
- 支持海量轻量级 Topic（百万级）元数据压缩管理
- 增强的死信队列（DLQ）与定时重试精准控制

**工程影响与选型建议：**

> 极大幅度降低海量历史消息留存的物理服务器磁盘成本。

### RocketMQ 5.0（2022 年 9 月）

**主要功能与架构演进：**

- 计算与存储分离架构：引入无状态 Stateless Proxy 节点，承接多语言与 gRPC 请求
- 全新的极简轻量级多语言 SDK（基于 gRPC 协议，告别复杂重客户端）
- 原生支持任意秒级的精准定时/延时消息（无需受限于固定的延时等级）

**工程影响与选型建议：**

> RocketMQ 发展历史上最大维度的架构云原生化演进。

### RocketMQ 4.5（2019 年 4 月）

**主要功能与架构演进：**

- 引入 DLedger 存储组件：基于 Raft 协议实现 CommitLog 多副本自动选主与数据同步
- 彻底消除了 Master-Slave 传统架构下的主从手动切换与脑裂丢数据风险

**工程影响与选型建议：**

> 金融级多活高可用与自动故障转移的核心基准。

## 5.0 架构升级建议
- 新项目推荐直接部署 5.x 架构（NameServer + Broker + Proxy），并采用基于 gRPC 的新版客户端驱动。
