## 使用约定

- 文档中每处关键结论引用应直接链接到支撑该结论的具体页面，而不是仅链接首页。
- 时效性强的结论（“当前最新”“默认值”）必须带核对日期。
- 每季度复核一次本清单；链接失效时优先修复而不是删除结论。
